تشغيل المشروع:
1. ثبّت Python 3.
2. افتح Terminal داخل المجلد.
3. نفّذ: pip install -r requirements.txt
4. نفّذ: python app.py
5. افتح: http://127.0.0.1:5000
6. لوحة الإدارة التجريبية: http://127.0.0.1:5000/admin

قاعدة البيانات SQLite باسم factory.db ويتم إنشاؤها تلقائياً عند أول تشغيل.
هذه لوحة تجريبية وليست مؤمنة للنشر العام بعد.
